# Storage Bin Content Typology

Functional contents of storage containers. Consult when routing parts; update whenever containers change.

## Container Typology Format

Each top-level storage container (box, cabinet, organizer) is defined by its primary `bin_number`, followed by bulleted sub-compartments or bags (`bin_number2`) with their functional component profiles.

```markdown
## `CONTAINER-BIN-ID` (Container Description)
* `COMPARTMENT-OR-BAG-LABEL`: Functional part types, form factors, or categories stored here.
```

---

## Storage Containers

### `BOX-CLEAR-01` (Bulk Clear Storage Box)
* `TUBING BAG`: Flexible tubing and hoses.
* `CABLE BAG`: Cables, cords, and wire harnesses.
* `FASTENERS BAG`: Zip ties, standoffs, and mechanical hardware.

### `DRAWER-ORGANIZER-01` (Component Cabinet)
* `A1`: Small passives (capacitors, resistors).
* `B1`: Discrete semiconductors and ICs.
* `C1`: Board-mount connectors and headers.

---

## Maintenance Rule
Update this file immediately whenever parts are added to new containers or bins are reorganized.
